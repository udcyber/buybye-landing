# BuyBye — Landing Page

Landing page du projet **BuyBye**, réalisée dans le cadre du Portfolio Project RNCP 5 à Holberton School.

## À propos

BuyBye est une application web qui aide les utilisateurs à mieux comprendre et analyser leur consommation personnelle (catalogue, liste d’envies, dashboard).
